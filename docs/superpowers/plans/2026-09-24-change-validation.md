# 변경 단계 검증

현재 main에서 작업한다. 전체 테스트나 앱 빌드를 변경마다 추가하지 않는다.

1. 저장 경로 변경에만 반응하는 push(main)/PR 워크플로를 추가한다. Node 24의 Windows와 Linux에서 저장 충돌, 외부 편집 HTTP, 감시 경로, 에셋 증분 검사 테스트를 실행한다. 로컬에서도 같은 명령을 제공한다.
2. 의존성 및 배포 구성 변경에만 반응하는 워크플로를 추가한다. 배포 파일 목록과 Docker COPY의 필수 입력을 검사하고, 실제 포터블과 같은 hoisted production 설치 및 Docker deps 단계를 확인한다. 앱 전체 빌드와 게시 작업은 하지 않는다.
3. 배포 입력 검사기는 실제 릴리스 파일 목록을 읽고, 패치 누락을 오류로 처리한다. 누락된 파일 및 Docker 입력을 주입하는 Node 테스트로 검증한다.
4. 기존 릴리스 워크플로에는 빠른 입력 검사만 설치 전에 연결한다. 태그 생성 전 전체 검증과 압축 해제 기동 검사는 유지한다.
5. 개발 문서와 0.9.42 패치노트에 변경 단계 검증을 기록한다. 관련 테스트와 워크플로를 검수한 후 main에 반영해 새 검사가 실제로 실행되는지 확인한다.
