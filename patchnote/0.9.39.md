# RisuBard v0.9.39

HTTP로 접속하는 로컬 호스팅 환경에서 플러그인 가져오기 오류를 수정했습니다.

## [안정성] 프리셋 외부 편집

- **외부 편집 시작 멈춤 수정:** 프리셋 파일을 안전하게 수정하기 위한 외부 편집 모드가 저장 대기에서 멈추던 문제를 수정했습니다.

## [안정성] 위키 갱신과 리부트

- **일반 응답의 Hypa 오류 수정:** 구형 장기기억 설정이 남아 있어도 일반 응답에서 내장 Hypa 요약기가 실행되지 않도록 수정했습니다. 플러그인에 제공하는 BardWiki 호환 기억은 유지합니다.

- **리부트 실패 원인 표시:** AI 응답 검증에 실패하면 검증기가 제공한 필드 누락이나 형식 불일치 등의 구체적인 이유를 오류창과 바드위키 작업 로그에 함께 표시합니다.

- **긴 위키 조회 결과 처리:** 사용자 토큰 예산 안의 긴 위키 문서나 과거 원문을 조회해도 오류로 중단되지 않도록 수정했습니다. 조회 결과와 프롬프트에 별도로 적용되던 글자 수 제한을 없애고, 문서별 발췌량은 실제 토큰 수와 사용자 설정을 기준으로 처리합니다.

- **사용자 메시지 제외 시 리부트:** 분석에서 사용자 메시지를 제외하도록 설정하면 위키 리부트가 근거 메시지 불일치 오류로 중단되던 문제를 수정했습니다. 분석할 원문과 근거 목록에 같은 설정을 적용합니다.

## [성능] 채팅과 프리셋 자동 저장

- **전체 DB 생성 횟수 감소:** 정본과의 일치가 확인된 저장소에서는 일반 채팅, 프리셋과 설정 자동 저장 때 변경된 파일을 기록하고, 전체 호환 DB는 읽기나 백업 등 필요한 시점에 생성합니다. 복잡한 변경과 검증되지 않은 저장소는 기존 저장 방식을 유지합니다.
- **프리셋 편집 응답성 개선:** 프롬프트 설정만 편집할 때 불필요한 전체 동기화를 줄이고, 검증된 직접 저장에서는 짧은 간격의 전체 비교 검사를 줄였습니다. 첫 검증과 전체 동기화, 오류 후 검증은 유지합니다.
- **저장 통계 보완:** 환경설정의 개발자 통계에서 호환 DB 생성 횟수와 p90 소요 시간을 별도로 확인할 수 있습니다.
- **에셋이 많은 저장소의 기록 비용 감소:** KV 색인을 기록할 때 메모리에서 생성한 JSON을 다시 파싱하던 중복 처리를 제거했습니다. 파일 형식과 디스크 기록 검증은 유지합니다.
- **작은 편집의 색인 기록 감소:** 저장 완료 상태를 작은 내부 파일에 기록해, 채팅이나 프리셋을 편집할 때마다 전체 에셋 색인을 다시 쓰던 비용을 줄였습니다. 정본 파일의 충돌 검사와 중단 복구는 유지합니다.

## [호환성] 로컬 호스팅 플러그인 가져오기

- **HTTP 환경 플러그인 지원:** 내부 IP의 HTTP 주소로 접속할 때 API v3 플러그인을 가져오면 정상 파일도 손상된 파일로 표시되던 문제를 수정했습니다. 플러그인 실행에 필요한 보안 난수를 HTTP에서도 지원되는 방식으로 생성합니다.
