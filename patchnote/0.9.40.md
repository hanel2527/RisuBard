# RisuBard v0.9.40

## [편의성] 중복 이름 자동 정리

- **가져온 캐릭터와 채팅 이름:** 이미 같은 표시 이름이 있으면 새 항목에 `(2)`, `(3)`처럼 번호를 붙입니다. 캐릭터와 채팅을 직접 이름 변경하거나 새 대화를 만들 때도 같은 규칙을 적용하며, 기존 데이터와 안정 ID는 바꾸지 않습니다.

## [안정성] 큰 채팅 분할 저장

- **선택적 청크 업로드:** 공통 설정의 저장 및 불러오기에서 큰 채팅을 나눠 전송하도록 설정할 수 있어 서버나 프록시의 요청 크기 제한에 대응합니다. 기본값은 꺼짐이며, 켜면 기본 8MiB 크기로 전송하고 1~64MiB 범위에서 조절할 수 있습니다.

## [성능] 플러그인 위키 반복 조회

- **BardWiki 컨텍스트 재사용:** 플러그인이 같은 대화를 반복 조회할 때 위키 컨텍스트 요청과 결과를 최대 30초 동안 공유해 중복 조회를 줄입니다. 대화나 설정이 바뀌면 새로 조회하며, 앱에서 위키를 변경하면 캐시를 비웁니다.

- **이름 기반 폴더 전환의 내부 검증:** 캐릭터와 대화의 ID를 유지하면서 이름 기반 폴더를 읽고 저장하는 공통 경로 처리를 추가했습니다. 시험 전환 후 재시작하거나 삭제해도 보존된 이전 폴더가 중복 자료로 다시 나타나지 않도록 했습니다. 백업에서도 이전 캐릭터와 대화 폴더를 중복 수집하지 않고 현재 폴더와 위키, 공유 자료와 휴지통을 보존합니다. 목록 수집 중 경로 정보가 바뀌거나 파일 접근에 실패하면 불완전한 목록을 사용하지 않습니다. 전체 백업과 캐릭터 패키지 검증이 남아 있어 실제 세이브의 자동 이전이나 전환 메뉴는 아직 제공하지 않습니다.

- **백업 복원 중단 안전성:** 파일 정본이 포함된 백업은 KV 색인, 캐릭터 파일과 인레이를 하나의 복구 가능한 게시 기록으로 교체합니다. 복원 도중 종료되면 다음 시작에서 남은 게시를 마치며, 실행 중인 서버도 복원된 KV와 이름 기반 경로 정보를 다시 불러옵니다. 기존 자료는 휴지통 아래에 보존합니다.

- **백업 복원 중단 안전성:** 파일 정본이 포함된 백업은 KV 색인, 캐릭터 파일과 인레이를 하나의 복구 가능한 게시 기록으로 교체합니다. 복원 도중 종료되면 다음 시작에서 남은 게시를 마치며, 실행 중인 서버도 복원된 KV와 이름 기반 경로 정보를 다시 불러옵니다. 기존 자료는 휴지통 아래에 보존합니다.

- **시작 시 대화 읽기 부담 감소:** 검증된 파일 저장소에서는 전체 세이브를 다시 조립하고 모든 대화를 읽는 대신, 먼저 설정과 대화 목록을 읽고 열린 대화만 불러옵니다. 기존 백업 가져오기와 구형 저장 데이터의 복구 경로는 유지합니다. 첫 저장 시 전체 대화를 준비하는 과정은 아직 남아 있습니다.

- **캐릭터별 에셋 전환 시험 기능:** 환경설정의 개발자 항목에서 캐릭터 하나를 골라 전용 이미지와 추가 에셋을 캐릭터 폴더에 복사하고 검증할 수 있습니다. 복사본은 확인 가능한 에셋 이름과 확장자를 사용하며, 이름이 겹치면 확장자 앞에 `(2)`, `(3)`을 붙입니다. 이전 해시 파일도 계속 읽으며 재검증할 때 새 이름으로 복사합니다. 평소 이미지를 읽을 때 반복하던 파일 정보 조회와 전체 해시 계산을 생략하고, 복사와 명시적 재검증 때 원본과 비교합니다. 같은 크기의 외부 파일 변경은 재검증 때 확인합니다. 기존 KV 원본과 백업 형식은 유지하며, 복사본 읽기 실패나 크기 변경 시 원본을 읽습니다. 상태 확인, 재검증과 기존 읽기로 되돌리기를 제공합니다. 캐릭터와 채팅 폴더 이름 자체는 아직 안정 ID를 유지하며, 전체 세이브의 V3 전환이나 성능 개선 완료를 뜻하지는 않습니다.

- **V3 폴더 이름 갱신 기반:** 시험용 V3 경로에서는 캐릭터와 채팅 이름을 바꾸거나 새 채팅을 만들 때 읽기 쉬운 폴더 이름도 함께 갱신할 수 있습니다. 같은 이름에는 번호를 붙이고, 삭제한 채팅의 폴더 이름은 다시 쓰지 않습니다. 이동이 중단되면 저장 journal로 이어서 복구합니다. 아직 일반 사용자 세이브에는 자동으로 켜지지 않습니다.

- 바드위키의 캐릭터 작성 지침을 개선했습니다. 최신 장면을 갱신할 때도 관계와 신뢰, 정신 상태, 지식, 약속, 부상과 중요한 장비 정보를 보존하도록 했습니다.
- 간결체가 서로 다른 사실까지 생략하지 않도록 기준을 명확히 하고, 필요한 경우 지속적인 인물 정보와 현재 상황을 별도 절로 정리하도록 했습니다.
- 인물 연속성 지침은 기본 위키 프리셋과 기존 사용자 프리셋에 공통 적용됩니다. 사용자 작성 블록은 유지하며, 통합 분석 요청에서는 양쪽 단계에 동일하게 포함된 지침의 중복을 줄였습니다.

## [안정성] 그리모어 대형 명단 분석

- **연표와 명단 분석**에서 인물별 분해로 늘어나는 예상 출력량을 고려해 배치를 나누고 추천 출력 한도를 계산합니다.
- **실패 배치 재시도**는 현재 설정으로 남은 항목을 다시 배치합니다. 잘린 응답에서 복구한 완료 항목은 보존하고, 남은 항목만 더 작은 배치로 이어서 분석합니다. 단일 항목의 반복 실패는 무한 재시도하지 않습니다.
- 플러그인이 제공한 **종료 사유와 토큰 사용량**을 분석 진단에 전달해 출력 한도 초과 원인을 확인할 수 있게 했습니다. 해당 정보를 반환하는 플러그인 버전이 필요합니다.

## [호환성] 아카라이브 챗 저장 서식

- **생각과 대사 색상:** `아카라이브 챗 저장기`로 복사할 때 생각과 대사의 글자색을 유지하고, 게시 시 노란 형광펜 배경이 생기는 문제를 수정했습니다.
- **이미지 프레임 제거:** 이미지 영역의 흰 테두리와 여백을 제거하고, 가운데 정렬과 둥근 모서리는 유지합니다. 이미지만 감싼 표와 중첩 영역도 함께 정리해 바깥 프레임이 남지 않도록 했습니다.

## [UI] 시작 화면 진행 상태

- **첫 화면 브랜딩:** 앱 코드와 화면 스타일을 불러오기 전에 RisuBard 배너를 먼저 표시합니다. 외부 폰트 로딩이 첫 화면을 가리지 않도록 했습니다.
- **실제 시작 단계 표시:** 저장소 초기화, 저장 데이터 읽기와 해석, 플러그인 로드 등 현재 작업을 표시합니다. 시작에 실패하면 해당 단계와 오류 내용을 화면에 남깁니다.
