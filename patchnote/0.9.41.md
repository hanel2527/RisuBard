# RisuBard v0.9.41

전체 캐릭터의 V3 저장 구조 시험 전환을 한 번에 시작하고, 중단 후 남은 대상을 이어서 처리할 수 있습니다. Realm 캐릭터 설명의 Proton Drive 링크에서 모듈도 바로 가져올 수 있습니다.

## [기능] 외부 파일 편집 자동 반영

- **설명과 로어북:** 캐릭터 `metadata.json`의 설명과 로어북, 전역 로어북 JSON을 외부 편집기로 저장하면 열린 앱에 자동 반영됩니다. 편집 모드와 페이지 새로고침 없이 바로 다음 대화에서 테스트할 수 있습니다.
- **에셋 폴더:** 캐릭터의 `assets` 폴더에 파일을 추가하거나 교체하고 제거하면 해당 캐릭터의 에셋 참조와 표시도 갱신됩니다. 새 파일은 추가 에셋으로 등록됩니다.
- **편집 내용 보호:** 진행 중인 채팅과 다른 항목의 앱 편집을 유지합니다. 같은 항목이 충돌하면 외부 파일을 적용하고 앱의 값을 복구 기록에 보존합니다. 잘못된 JSON은 알림 후 수정될 때까지 저장과 새 전송을 보류합니다.
- **시작 지연 수정:** 이전 V3 전환에서 남은 미등록 에셋 복사본을 새 파일로 오인해 시작 화면에서 오래 대기하던 문제를 수정했습니다. 실제 새 에셋도 묶어서 등록해 파일마다 전체 저장 색인을 다시 쓰지 않습니다.
- **동시 편집과 재시도 강화:** 서버가 수신한 앱 편집과 외부 편집이 겹쳐도 앱 수정본을 서버 복구 파일에 보존합니다. 반영 중 저장 실패나 서버 재시작이 발생하면 미완료 반영을 다시 시도하며, 복구 기록은 전체 백업에도 포함됩니다. V3 전환 후 대표 이미지 수정이 추가 에셋으로 잘못 등록되는 문제도 수정했습니다.
- **신규 캐릭터 V3 기본 배치:** 새로 생성하거나 새 ID로 가져온 캐릭터는 처음부터 이름 기반 V3 폴더에 저장합니다. 기존 캐릭터와 전체 백업 복원의 구조는 유지합니다. 앱에서 추가하거나 교체하고 제거한 에셋도 V3 폴더에 반영하며, 제거한 복사본은 휴지통에 보관합니다. 공유 에셋 원본과 다른 캐릭터의 표시는 유지합니다.
- **동시 편집과 재시도 강화:** 서버가 수신한 앱 편집과 외부 편집이 겹쳐도 앱 수정본을 서버 복구 파일에 보존합니다. 반영 중 저장 실패나 서버 재시작이 발생하면 미완료 반영을 다시 시도하며, 복구 기록은 전체 백업에도 포함됩니다. V3 전환 후 대표 이미지 수정이 추가 에셋으로 잘못 등록되는 문제도 수정했습니다.
- **신규 캐릭터 V3 기본 배치:** 새로 생성하거나 새 ID로 가져온 캐릭터는 처음부터 이름 기반 V3 폴더에 저장합니다. 기존 캐릭터와 전체 백업 복원의 구조는 유지합니다. 앱에서 추가하거나 교체하고 제거한 에셋도 V3 폴더에 반영하며, 제거한 복사본은 휴지통에 보관합니다. 공유 에셋 원본과 다른 캐릭터의 표시는 유지합니다.

## [중요 수정] 업데이트 시 개인 파일 보존

- **설치 폴더에 추가한 자료 보존:** 배치 업데이터와 Unix 업데이트가 설치 폴더 전체를 정리하던 문제를 수정했습니다. 새 배포에 포함된 항목만 교체하며, 설치 폴더 바로 아래에 별도로 추가한 폴더와 파일은 유지합니다. `save`, `backups`와 사용자 설정 파일도 보존합니다.
- **기존 버전에서 처음 업데이트할 때:** 교체 작업은 기존 업데이터가 실행하므로 새 버전을 받는 것만으로 첫 업데이트가 보호되지는 않습니다. 기존 업데이터를 먼저 수정본으로 교체하거나, 새 버전을 별도 폴더에 설치해 주세요. `server`, `dist`, `node_modules` 등 프로그램 폴더 내부는 교체 대상입니다.

## [수정] 저장 진단의 현재 상태 구분

- **현재 실행과 누적 기록 분리:** 저장 진단 파일에서 현재 서버 실행의 결과와 과거 누적 기록을 구분합니다. 이전 버전에서 발생한 오류가 현재 실행의 오류로 합산되지 않으며, 과거 기록은 `history`에 보존합니다.

## [편의성] Realm에서 모듈 바로 가져오기

- **모듈 가져오기:** 캐릭터 설명에 Proton Drive 공유 링크가 하나 있으면 다운로드 버튼 옆에서 모듈을 바로 가져올 수 있습니다. 단일 `.risum` 파일은 진행률을 표시하며 다운로드 후 자동으로 임포트하고, 폴더나 다른 파일 및 비밀번호가 필요한 링크는 원본 열기를 안내합니다. 설명의 기존 링크도 그대로 사용할 수 있습니다.

## [기능] 전체 캐릭터 V3 시험 전환

- **전체 전환과 재개:** 개발자 설정에서 삭제되지 않은 캐릭터를 하나씩 전환합니다. 이미 전환된 캐릭터는 건너뛰고, 실패한 대상과 에셋 검증은 다시 실행할 때 재시도합니다.
- **진행 확인과 중단:** 캐릭터별 처리 결과를 확인하고 중단할 수 있습니다. 화면을 나가면 진행 중 요청까지만 처리하며, 다시 실행하면 서버에 저장된 상태를 확인해 이어갑니다. 기존 캐릭터별 되돌리기도 사용할 수 있습니다.
- **전환 범위:** 공유 에셋, 바드위키와 모듈의 위치 및 기존 백업 형식은 유지합니다. 시험 전환 전에는 백업을 보관해 주세요.
