# RisuBard v0.9.48

채팅 전송 준비 중의 상태 표시와 재시도를 개선하고, 메시지 본문과 부가 정보를 포함한 전체 크기를 구분합니다.

## [안정성] 채팅 전송 준비와 재시도

- **중복 전송 방지:** 입력 번역과 전송 준비 중에는 진행 상태를 표시하고 반복 클릭으로 같은 입력이 여러 번 전송되지 않도록 했습니다. 입력 처리에 실패하면 오류를 알리고 초안을 유지합니다.
- **동기화 대기 해제:** 전송 전 파일 동기화를 기다리는 동안 취소할 수 있으며, 30초를 넘으면 안내 후 다시 시도할 수 있습니다. 대기를 끝낸 요청은 동기화가 늦게 완료되어도 뒤늦게 전송되지 않습니다.
- **전송 대상 보호:** 동기화를 기다리는 동안 다른 대화로 이동하면 전송을 중단해, 새로 선택한 대화에 응답이 생성되지 않도록 했습니다.

## [UI] 메시지 크기 구분

- **본문과 전체 크기:** 메시지 정보에서 `본문 크기`와 `메시지 전체 크기`를 UTF-8 바이트 기준으로 표시합니다. 전체 크기에 프롬프트, 번역 기록과 복구 정보가 포함되며 전송 토큰 수와는 다르다는 안내를 추가했습니다.
