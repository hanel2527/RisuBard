# RisuBard v0.9.74

## [수정] 라이트보드 리롤 같은 버튼이 다른 챗을 덮어쓰던 문제

메시지 안의 버튼(라이트보드의 다시 생성 버튼, 봇이나 모듈의 트리거 버튼)은 누른 챗이 아니라, 처리가 끝난 순간에 열려 있는 챗에 결과를 썼습니다. 리롤처럼 오래 걸리는 버튼을 누르고 기다리는 동안 다른 챗이나 다른 봇으로 옮기면, 그 챗의 내용이 버튼을 누른 챗의 내용으로 통째로 바뀌었습니다. 챗 목록에 같은 챗이 두 개 생기고 원래 대화가 사라진 것처럼 보였습니다.

- 이제 버튼 결과는 항상 버튼을 누른 챗에만 들어갑니다. 기다리는 동안 다른 챗이나 봇으로 옮겨도 그쪽은 바뀌지 않습니다.
- 처리 중에 버튼을 누른 챗을 지웠다면 결과를 버립니다. 다른 챗에 대신 쓰지 않습니다.
