# RisuBard v0.9.78

## 바드위키에 같은 이름이나 별칭의 문서가 생기던 문제

위키 작성 AI가 이미 있는 인물을 다른 이름으로 부르며 새 문서를 제안하면, 그 별칭이 기존 문서의 이름과 같아도 새 문서가 만들어졌습니다. 그 결과 같은 이름이나 별칭을 가진 문서가 여러 개 생겨 `[[이름]]` 링크가 어느 문서로 연결될지 정해지지 않았습니다.

- 새 문서 후보의 별칭이 기존 문서의 이름과 같으면, 새 문서를 만들지 않고 기존 문서를 갱신하며 새 이름을 별칭으로 더합니다. 대화에 실제로 나온 별칭만 이 판단에 씁니다.
- 한 번의 분석에서 같은 인물이 여러 이름으로 제안되면 하나의 문서로 모읍니다.
- `선배`처럼 여러 인물이 함께 쓰는 별명만 겹칠 때는 서로 다른 인물로 보고 합치지 않습니다. 대신 이미 다른 문서가 쓰는 별칭은 새로 붙이지 않아 링크가 엇갈리지 않습니다.
- 이름이 여러 기존 문서와 겹쳐 어느 문서인지 정할 수 없으면 새 문서를 만들지 않고 분석 결과에 `이름 충돌` 경고를 남깁니다.
